# Sicherheitsrichtlinie

## Eine Schwachstelle melden

Bitte veröffentliche ausnutzbare Schwachstellen, Tokens, Pod-Adressen oder
private Daten nicht in einem öffentlichen Issue. Nutze bevorzugt GitHubs
**Private vulnerability reporting** unter **Security → Advisories → Report a
vulnerability**. Falls diese Funktion nicht angeboten wird, kontaktiere den
Repository-Maintainer zunächst über einen privaten Kanal.

Nenne betroffene Version beziehungsweise Image-Digest, Auswirkung,
Reproduktionsschritte und einen möglichen Fix. Allgemeine
Konfigurationsfragen können als normales Issue gestellt werden.

## Geltungsbereich

Unterstützt wird jeweils der aktuelle Release-Tag. Das Projekt verwaltet keine
RunPod-, Hugging-Face- oder Open-WebUI-Accounts und kann kompromittierte Secrets
nicht für Nutzer sperren. Ein offengelegtes Secret muss beim jeweiligen
Anbieter sofort widerrufen und ersetzt werden.
